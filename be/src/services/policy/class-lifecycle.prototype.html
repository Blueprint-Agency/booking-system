What does it mean for a class to be over?

Today the system has one idea of a class ending: the clock passes ends_at, and the class reads completed. Nobody decides anything — a background job silently marks every un-ticked member a no-show and burns their credit within 60 seconds of the last pose. This demo asks whether ended should really be two things: the hour is over, and the class has been closed out by a human. Flip the mode switch and run the same scenario twice to feel the difference.
